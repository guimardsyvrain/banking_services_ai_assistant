# Banking Services – AI Credit Risk & Loan Advisory Assistant

An AI-powered decision-support application combining:

- Credit risk classification
- Expected Loss regression
- Retrieval-Augmented Generation (RAG)
- Local Large Language Model
- Explainable AI
- MLOps with MLflow
- REST API with FastAPI
- SQLite relational database
- ChromaDB vector database

The application is designed to run locally using lightweight,
open-source technologies and resource-efficient machine learning
algorithms.
